# 191 Manager V2
نسخة PWA ثابتة لمشروع 191 Fast-Food.

## الاستضافة السهلة
1. أنشئ حساب GitHub.
2. أنشئ Repository جديد باسم `191-manager`.
3. ارفع `index.html` و`manifest.webmanifest` و`sw.js`.
4. Settings > Pages > Deploy from branch > main > /(root) > Save.
5. انتظر نشر الموقع وافتح رابط `https://USERNAME.github.io/191-manager/`.
6. على iPhone: افتح الرابط في Safari > Share > Add to Home Screen.

## مهم
هذه النسخة تحفظ البيانات داخل متصفح الجهاز (localStorage). لذلك هي مناسبة كبداية وتجربة على جهاز واحد، وليست بعدُ نظامًا متعدد المستخدمين أو قاعدة بيانات سحابية. لا تضع بيانات حساسة فيها.
